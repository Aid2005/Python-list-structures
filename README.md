# Custom List Data Structures in Python

This project features custom implementations of array-based and node-based list data structures in Python, created to demonstrate low-level memory management and pointer operations.

## Description

- **Array-Based List (`ArrayList`)**: Uses low-level C-style arrays (`ctypes`) to manage fixed-capacity element storage and manual pointer positioning.
- **Singly Linked List (`SinglyLinkedList`)**: Implements a node-based structure with manual tracking of `head`, `tail`, and `current` pointers alongside left/right partition length logic.
- **CLI Drivers (`main.py`)**: Interactive terminal drivers for both structures, enabling real-time testing of pointer navigation, element insertion, deletion, and filtering (even/odd/difference logic).
- **Memory Demo (`memory_demo.py`)**: Demonstrates Python object mutability, memory address tracking using `id()`, and string interning optimizations.
